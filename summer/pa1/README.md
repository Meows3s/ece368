available commands:
open (opens new window) args: int winNum (name of window to open)
close (closes window) args: int winNum (name of window to close), string all (closes all windows)
switch (switches focus to window) args: int winNum (name of window to switch focus to)
list (lists all windows) (no arguments)

debug mode can be enabled by setting DEBUG to 1 in defs.h
